LA VISTA REAL ESTATE — PREMIUM GOLD REDESIGN
================================================

WHAT'S INCLUDED
- index.html — full one-page website
- style.css — responsive design and luxury gold / black / ivory styling
- script.js — mobile navigation and small interface enhancements

HOW TO OPEN WITHOUT VS CODE
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome or another browser.

HOW TO OPEN IN VS CODE
1. Extract the ZIP file.
2. In VS Code, choose File > Open Folder.
3. Select the extracted lavista-premium-rebuild folder.
4. Open index.html. For local preview, use Live Server if installed.
